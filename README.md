## Business Problem & Objectives

High-growth SaaS businesses face substantial revenue contraction when customer onboarding and retention issues are detected too late. This project provides:
1. **Revenue Concentration Analysis:** Evaluates MRR (Monthly Recurring Revenue) distribution across geographic territories, business tiers, and product portfolios.
2. **Churn Risk Signals:** Identifies statistical drivers of churn—specifically the interaction between customer satisfaction (CSAT) scores and customer support ticket volume within 90-day windows.
3. **Actionable Risk Stratification:** Provides an analytical framework (via SQL and Python) to rank active customers into actionable risk categories (*Critical Risk*, *Moderate Risk*, *Healthy*).

---

## Key Findings & Data Insights

* **Support Escalation Threshold:** Accounts logging **4 or more support tickets** within 90 days exhibit a churn rate jump to **>42%**, compared to baseline churn of 14% for accounts with 0-1 tickets.
* **CSAT Inflection Point:** Retention drops sharply once CSAT falls below **5/10**. 
* **Revenue Anchor:** North America and Europe represent **>70% of total recurring revenue**, with Enterprise accounts driving the highest average revenue per unit (ARPU).

## Setup & Local Execution

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/executive-sales-churn-analytics.git
cd executive-sales-churn-analytics
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the analysis script
```bash
python scripts/run_analysis.py
```
